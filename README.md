# MCplusplus

## Introduction

A vanilla-style survival expansion mod,all new content fits the original Minecraft art style 
and stays true to the vanilla Minecraft experience.

## Dependencies

- Minecraft: >= 26.1.2
- Fabric Loader: >= 0.19.3
- Java: >= 25
- Fabric API: >= 0.155.2+26.1.2
